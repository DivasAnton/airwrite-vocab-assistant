Sprint 4 - Index Finger Tracking

Decision kept from Sprint 3:
- Handedness is not changed.
- Display labels are not swapped.
- Coordinates are not inverted.
- Canvas behavior is not changed.
- Prediction behavior is not changed.
- The existing mirror -> detect -> track pipeline is kept.

Files added:
- app/vision/finger_tracking_result.py
  Added immutable FingerTrackingResult with raw point, smoothed point, normalized point, tracking status, timestamp, hand index, and landmark index.
- app/vision/index_finger_tracker.py
  Added IndexFingerTracker to select the first hand, read landmark 8, convert normalized coordinates to pixels, clamp frame boundaries, smooth movement, and reset when tracking is lost.
- app/vision/finger_tracking_renderer.py
  Added FingerTrackingRenderer to draw raw and/or smoothed fingertip debug points.
- tests/test_index_finger_tracker.py
  Added tests for normalized-to-pixel conversion, clamping, landmark index 8, smoothing, lost-hand reset, invalid frame dimensions, and missing landmarks.
- tests/test_finger_tracking_renderer.py
  Added renderer tests for untracked state, tracked point drawing, input immutability, disabled drawing options, boundary points, and invalid frames.
- docs/sprint_4_finger_tracking_test_plan.md
  Added manual webcam test plan for cursor tracking, jitter observation, alpha tuning, and edge behavior.

Files changed:
